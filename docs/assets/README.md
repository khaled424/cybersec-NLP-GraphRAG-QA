# Illustrations de la documentation

Stockez ici les schémas et figures générés pour les ADR et les rapports,
notamment les architectures NLP, graphe de connaissances et Graph-RAG.

Utilisez des noms explicites et référencez les fichiers depuis la
documentation avec des chemins relatifs. Gardez les sources modifiables des
diagrammes lorsque c'est possible; n'y placez pas de données ou de résultats
bruts volumineux.
