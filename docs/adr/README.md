# Architecture Decision Records

Ce dossier conserve les décisions d'architecture qui ont un impact durable
sur le projet.

Créez un fichier numéroté, par exemple `0002-vector-index.md`, pour chaque
nouvelle décision. Décrivez brièvement son contexte, la décision retenue,
les alternatives importantes et ses conséquences. Utilisez les statuts
`Proposed`, `Accepted` ou `Superseded`; lorsqu'une décision est remplacée,
laissez l'ancien ADR en place et référencez le nouveau.

Voir [0001-initial-architecture.md](./0001-initial-architecture.md) comme
exemple.
