# Expériences

Consignez ici les entraînements, évaluations et expériences de NLP, de
classification zero-shot et de Graph-RAG qui produisent des résultats utiles.

Créez un fichier par expérience et indiquez au minimum :

- la question étudiée et la date;
- la source et la version des données, les splits et le prétraitement;
- le modèle, les paramètres et les graines aléatoires utilisés;
- les commandes pour reproduire l'expérience;
- les métriques obtenues et les limites observées.

Ne placez pas les données, les poids de modèles ou d'autres artefacts
volumineux dans ce dossier; indiquez plutôt comment les générer ou les obtenir.
